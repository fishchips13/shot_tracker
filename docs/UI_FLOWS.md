# UI Flows

## Screen inventory

| Screen | Purpose | Primary actions | Disabled/non-actions | Outbound navigation |
|---|---|---|---|---|
| Track | Start or resume | Start Workout, Resume Workout | Delete is overflow only | Selection or stored active drill |
| Zone selection | Choose one/two zones | Toggle, Continue | Third zone alerts | Drill setup |
| Drill setup | Choose selected zone and goal | Start | No shot entry | Active drill |
| Active drill | Fast locked tracking | Make, Miss, Undo, switch, Finish | Court disabled | Summary or another active drill |
| Drill summary | Review drill | Switch, finish workout | No shot entry | Active drill or workout summary |
| Workout summary | Review workout | Done | Read-only | Track |
| History | Browse completed workouts | Open card | Drafts omitted | Workout summary |
| Stats | Career dashboard | Read data | Heat map read-only | None |

## Interaction hierarchy

    Active zone
    → stats and goal progress
    → Make/Miss
    → Undo
    → finish/more actions

## Visual language

Current source uses sports-forward cards, orange-tinted backgrounds, large Make/Miss controls, zone colors, goal progress, feedback badges, and heat-map intensity. Intended direction remains a premium youth basketball training app: energetic but restrained, visibly rewarding, and not a notes-style list.
